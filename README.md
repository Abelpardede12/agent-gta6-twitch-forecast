Forecasts GTA VI's launch-day Twitch viewers hour by hour from the first hour's print, using the median launch-day curve of past midnight-local console launches. GTA VI unlocks at midnight local time, rolling country by country, so the UTC release day is a staircase, not one spike: the model takes each comparable launch's hourly curve, divides every hour by that launch's hour-1 print, and uses the median log ratio plus a robust log spread per hour. Peak lands in the first evening (hour 19, 19:00–20:00 UTC) at about 2.4x the first hour, then decays overnight.

